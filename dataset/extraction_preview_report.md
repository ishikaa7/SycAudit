**Duplicate semantics**: the `duplicates` count below is the number of rows whose content (prompt, response) is identical to a row already seen. This arises (a) in schis02 when the same completion is repeated across `sample_idx`/seed rows (temperature 0 produces identical text), and (b) in camilablank because some source files literally repeat identical lines (e.g. `triviaqa_rated` repeats rows sharing the same `id` and identical `history`). One representative record per unique (prompt, response) pair is kept in the valid pool; content duplicates are never double-counted as final candidates.
